# Методика расчёта

## 1. Геометрическое планирование

На первом этапе строится геометрический путь методом RRT. Дерево начинается в начальной точке. На каждой итерации выбирается случайная точка в рабочей области либо конечная точка с вероятностью `goalBias`. Новая вершина добавляется только при отсутствии столкновения с препятствиями.

## 2. Сглаживание пути

После нахождения пути выполняется shortcut-сглаживание. Случайно выбираются две точки пути; если прямой отрезок между ними не пересекает препятствия, промежуточный участок удаляется.

## 3. Minimum-snap траектория

Точки сглаженного RRT-маршрута передаются в `minsnappolytraj`. Времена прохождения точек рассчитываются по длинам сегментов и опорной скорости `vRef`: для каждого сегмента используется `max(длина / vRef, dt)`. На выходе формируется дискретная 3D-траектория с заданной высотой `zRef`, а также её производные: скорость, ускорение, jerk и snap.

## 4. Динамическая проверка

Сгенерированная minimum-snap траектория передаётся в регулятор слежения и динамическую модель квадрокоптера. Затем выполняется численное интегрирование:

```text
x_dot = v
m * v_dot = m * g * e3 - f * R * e3
R_dot = R * hat(Omega)
J * Omega_dot + Omega x J * Omega = M
```

Для формирования входов `f` и `M` используется вспомогательный регулятор слежения. После расчёта `f` и `M` они преобразуются в тяги четырёх двигателей. Тяги ограничиваются диапазоном `[0, fMaxPerMotor]`.

## 5. Критерии качества

В проекте рассчитываются:

- время расчёта маршрута;
- длина пути;
- максимальная кривизна;
- средняя кривизна;
- максимальная ошибка слежения;
- конечная ошибка слежения;
- максимальная тяга двигателя;
- средняя тяга двигателя;
- признак динамической реализуемости.
