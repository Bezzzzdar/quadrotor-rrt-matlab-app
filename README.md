# RRT-планирование траектории мультироторного ЛА в MATLAB App

Проект реализует MATLAB-приложение для курсовой работы на тему:

> Планирование траектории движения мультироторного летательного аппарата при наличии препятствий.

Приложение строит геометрический маршрут методом RRT в двумерной рабочей области с прямоугольными статическими препятствиями, преобразует точки маршрута в minimum-snap траекторию через `minsnappolytraj`, затем проверяет её через моделирование динамики квадрокоптера.

## Возможности

- ввод размеров рабочей области;
- ввод начальной и конечной точек;
- редактируемая таблица прямоугольных препятствий;
- ввод параметров RRT:
  - шаг роста дерева;
  - вероятность выбора цели;
  - максимальное число итераций;
  - порог достижения цели;
  - шаг проверки столкновений;
  - число итераций сглаживания;
- ввод параметров симуляции:
  - опорная скорость;
  - шаг интегрирования;
  - опорная высота;
  - допустимая ошибка слежения;
- генерация minimum-snap траектории по точкам RRT;
- моделирование движения по сгенерированной траектории;
- отображение:
  - карты и препятствий;
  - дерева RRT;
  - minimum-snap маршрута;
  - траектории динамической модели;
  - ошибки слежения;
  - тяг четырёх двигателей;
- экспорт итоговых метрик в CSV.

## Использованная модель динамики

В проект интегрирована модель квадрокоптера на SE(3) из статьи:

Lee, T., Leok, M., McClamroch, N. H. *Control of Complex Maneuvers for a Quadrotor UAV using Geometric Methods on SE(3)*.

Используемые уравнения:

```text
x_dot = v
m * v_dot = m * g * e3 - f * R * e3
R_dot = R * hat(Omega)
J * Omega_dot + Omega x J * Omega = M
```

Связь суммарной тяги и моментов с тягами двигателей:

```text
[f; M1; M2; M3] = A * [f1; f2; f3; f4]
```

где `A` — матрица смешивания тяг, зависящая от плеча `d` и коэффициента `c_tau_f`.

Важно: RRT остаётся геометрическим планировщиком. Minimum-snap траектория строится по найденным точкам маршрута, а динамическая модель используется на этапе проверки реализуемости этой траектории.

## Запуск приложения

1. Откройте MATLAB.
2. Перейдите в корень проекта.
3. Выполните:

```matlab
run('scripts/run_app.m')
```

или откройте файл `scripts/run_app.m` и запустите его.

## Запуск без интерфейса

```matlab
run('scripts/run_demo.m')
```

## Ограничения

- Препятствия имеют прямоугольную форму и задаются в плоскости XY.
- Планирование выполняется в 2D, а динамическая проверка использует 3D-модель квадрокоптера с постоянной заданной высотой `z_ref`.
- Регулятор слежения добавлен для численного моделирования и проверки реализуемости; он не является предметом теоретического доказательства устойчивости в проекте.
- Модель не учитывает аэродинамическое сопротивление, насыщение скорости вращения двигателей и задержки исполнительных механизмов.
